# 要支援？要介護？いったい何が違うの？

「母は要支援2になったらしい」「父は要介護1から2に変わったんだって」

そんな話を聞いても、介護に関わったことがなければ、何が違うのか分からないですよね。

そもそも要支援と要介護って何？ 数字が大きくなるとどうなるの？

今回は、介護保険の基本を分かりやすく解説します。

## そもそも「要支援」「要介護」って何？

要支援・要介護とは、日常生活でどのくらい支援や介護が必要なのかを表す、介護保険の認定区分です。

要支援は、基本的な生活はおおむね自分でできるものの、一部に支援が必要な状態です。

要介護は、食事や入浴、着替えなど、日常生活で介護が必要な状態です。

ただし、実際の状態は人によって異なります。

## 要支援1・2、要介護1〜5の違い

認定区分は全部で7段階あります。

| 区分 | 状態の目安 |
|---|---|
| 要支援1 | 基本的な生活はほぼ自分でできるが、一部に支援が必要 |
| 要支援2 | 生活機能が低下し、継続的な支援が必要 |
| 要介護1 | 立ち上がりや身の回りのことなどに部分的な介助が必要 |
| 要介護2 | 入浴や着替え、移動など、介助が必要な場面が増える |
| 要介護3 | 日常生活の多くの場面で介助が必要 |
| 要介護4 | 日常生活の大部分で介助が必要 |
| 要介護5 | 生活全般にわたり、継続的で手厚い介護が必要 |

※これは一般的な目安です。実際の認定は、身体の状態だけでなく、認知機能や介護に必要な手間なども考慮して決まります。

## 要支援2と要介護1は、何が違う？

この2つは特に分かりにくい区分です。

要支援2と要介護1は、介護の必要度を測る基準上、同じ範囲に入ります。

そのうえで、認知機能の状態や、今後も介護が必要な状態が続く可能性などを考慮して区分されます。

また、要介護1と2についても、単に「歩けるかどうか」で決まるわけではありません。

同じ区分でも、身体の介助が必要な方と、認知症による見守りが必要な方では、生活の様子が異なります。

## 認定されると何が変わる？

認定を受けると、区分や本人の状態に応じて、介護保険サービスを利用できます。

例えば、デイサービス、訪問介護、福祉用具の貸与、ショートステイなどです。

ただし、要支援と要介護では、利用できるサービスや制度が異なる場合があります。

自己負担は原則1〜3割で、所得などによって異なります。

## 誰が、どうやって決めるの？

要支援・要介護の区分は、市区町村が審査を経て認定します。

流れは次のとおりです。

1. 市区町村に申請する
2. 認定調査を受ける
3. 主治医の意見書を作成してもらう
4. 介護認定審査会などで審査・判定される
5. 認定結果が通知される

申請から認定結果の通知までは、原則30日以内とされています。

## 迷ったら、まずは相談を

「まだ介護が必要というほどではないかも」

そんな段階でも、地域包括支援センターに相談できます。

要支援・要介護の認定は、本人に「できない」という評価を付けるためのものではありません。

必要な支援を受けながら、その人らしい暮らしを続けるための仕組みです。

まずは言葉の意味を知ることから、介護について考えてみませんか。
