# 離れて暮らす親の見守り、何から始める？

離れて暮らす親が年齢を重ねるにつれて、「最近、元気にしているかな」「一人で暮らしていて大丈夫かな」と気になることが増えるかもしれません。

とはいえ、毎日電話をかけたり、頻繁に様子を見に行ったりするのは難しいものです。

高齢の親を見守る方法は、カメラやセンサーなどの機器だけではありません。日々の連絡の取り方を工夫したり、必要に応じて見守りサービスを取り入れたりする方法もあります。

大切なのは、親の暮らし方や気持ちに合った方法を選ぶことです。

## まずは、普段の様子を知ることから

離れて暮らしていると、親の生活の小さな変化には気づきにくいものです。

まずは、無理なく連絡を取り合える習慣をつくってみましょう。

例えば、週に何度か電話で話したり、短いメッセージを送り合ったりするだけでも、普段の様子を知るきっかけになります。

会話の中で、食事や睡眠、最近の外出の様子などを自然に聞いてみるのもよいでしょう。

見守りを特別なこととして始めるよりも、普段のコミュニケーションの延長として取り入れる方が、お互いの負担を抑えやすくなります。

## 見守りサービスにはどんな種類がある？

家族だけで様子を確認することが難しい場合は、見守りサービスを利用する方法もあります。

目的によって、適した仕組みは異なります。

| 方法       | 特徴                  | 向いている場面           |
| -------- | ------------------- | ----------------- |
| 電話・メッセージ | 本人と直接やり取りできる        | 日常の安否確認           |
| 見守りセンサー  | 室内の動きなどから生活の様子を把握する | 一人暮らしの生活確認        |
| 見守りカメラ   | 映像で室内の様子を確認する       | 本人が同意し、映像確認が必要な場合 |
| GPS端末    | 対応する端末で位置情報を確認する    | 外出先の居場所が気になる場合    |
| 見守りQRコード | 発見した方から家族などへ連絡できる   | 外出先で困ったときの連絡手段    |

それぞれに役割があり、一つの方法ですべてを補えるわけではありません。

例えば、自宅での生活が心配な場合はセンサー、外出先の居場所が気になる場合はGPS端末など、気になる場面に合わせて選ぶことが大切です。

## 親が嫌がらない見守り方法を選ぶ

見守りを考えるときに忘れたくないのが、ご本人の気持ちです。

家族としては安心のために導入したいサービスでも、親にとっては「監視されているようで落ち着かない」と感じることがあるかもしれません。

特にカメラや位置情報を利用するサービスでは、何を確認するのか、誰が情報を見るのかを事前に話し合っておくと安心です。

機器の操作や充電が負担にならないかも確認しましょう。

便利な機能が多いことよりも、本人が無理なく使い続けられることが重要です。

## 外出時の安心も考えておく

自宅での安否確認だけでなく、外出時の備えについて考えておくこともできます。

例えば、出先で道に迷ったり、家族に連絡したくても携帯電話を持っていなかったりする場面です。

こうした場合に備え、持ち物に緊急連絡先を記載する方法があります。ただし、電話番号などの個人情報を人目に触れる場所に書くことに抵抗がある方もいるでしょう。

株式会社QRingの「つながるQR」は、バッグなどに付けたQRコードを発見者がスキャンし、互いの電話番号を知らせずに通話できる仕組みです。

GPSのように居場所を追跡するものではなく、困ったときに家族などへ連絡するための選択肢です。

詳しくは「高齢者の外出時の見守りに、つながるQR」をご覧ください。

## 無理なく続けられる方法を

親の見守りに、すべての家庭に共通する正解があるわけではありません。

毎日の電話が合う家庭もあれば、センサーなどのサービスを取り入れることで負担を減らせる家庭もあります。

まずは親がどのように暮らしたいと思っているのか、家族が何を心配しているのかを話し合ってみましょう。

お互いの生活を大切にしながら、無理なく続けられる方法を見つけることが、安心につながります。
