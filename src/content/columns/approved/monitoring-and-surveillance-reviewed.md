# 「見守り」と「監視」は何が違う？家族の安心と本人の自由を考える

見守りと監視は、機器の種類だけでは分けられません。何のために、誰が、どこまで情報を確認するのか。その目的や使い方、本人の受け止め方によって意味が変わります。

離れて暮らす親や、帰宅が遅い子どもを心配する気持ちは自然です。その安心のために、本人にどんな負担が生じるかも考えておきたいところです。

## 見守りと監視の違いは？

見守りは、本人が安心して生活できるように支えることを目的とします。一方、監視という言葉には、行動を継続的に確認し、管理するという意味合いがあります。ただし、同じ機器を使っていても、目的や使い方によって本人の受け止め方は変わります。

例えば、位置情報を共有することが安心につながる人もいれば、常に居場所を知られることに抵抗を感じる人もいます。

関連する内容として「[離れて暮らす親の見守り、何から始める？](/column/elderly-monitoring/)」も参考になります。

## 心配だから全部知りたい？

家族が心配なときほど、できるだけ多くの情報を知りたくなるものです。しかし、本当に必要な情報は何でしょうか。「帰宅が遅れたときに連絡したい」「困ったときに助けを求められるようにしたい」

目的を具体的にすると、必要な仕組みを選びやすくなります。

関連する内容として「[高齢者の見守りに、つながる安心を。](/column/elderly-monitoring-contact-system/)」も参考になります。

## 本人の意思を尊重する

見守りの方法を決める際には、可能な限り本人と話し合うことが大切です。どの情報を共有するのか。誰が確認できるのか。いつ、どのような場合に連絡するのか。こうした点を明確にしておくと、安心感につながります。

本人の判断能力や安全面に課題がある場合は、家族だけで抱え込まず、医療・介護などの専門職に相談することも重要です。

| 項目 | 話し合うこと |
| --- | --- |
| 目的 | どんな場面で、どのような支援が必要か |
| 情報の範囲 | 位置・映像・連絡履歴など、必要な情報だけを選ぶ |
| 頻度・閲覧者 | 常時見るのか、必要時のみか。誰が閲覧するか |
| 保存と見直し | いつまで残し、いつ削除するか。本人の希望が変わったらどうするか |
| 連絡が取れないとき | 次に連絡する人、訪問や公的機関への相談の目安 |

例えば、外出を続けたい本人と心配な家族で、まず定時の電話を試し、必要なら位置確認を追加するなど、状況に合わせて見直します。GPSやカメラが必ず監視になるわけではなく、目的・使い方・本人の意向が重要です。

## 常に居場所を把握する以外の方法

見守りには、GPSによる位置情報の確認だけでなく、定期的な電話や訪問、緊急時の連絡手段など、さまざまな方法があります。例えば「つながるQR」は、QRコードをスキャンした発見者が、登録者と電話番号を知らせずに通話できる仕組みです。

位置を常時追跡するサービスではありませんが、外出先で周囲の人から連絡を受けるための備えとして利用できます。

## 本人と共有する情報の範囲を決める

見守りの目的は、本人の自由を奪うことではありません。安心して生活できる環境を整えることです。家族の心配と本人の気持ち、その両方を大切にしたいですね。
