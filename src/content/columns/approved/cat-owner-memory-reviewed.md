# 猫は何日くらい飼い主を覚えている？猫の記憶と認識の不思議

猫が飼い主を何日で忘れるのか、すべての猫に当てはまる日数はわかっていません。旅行や出張のあとにそっけなく見えても、それだけで忘れられたとは判断できません。

一方、飼い主の声を聞き分ける反応は研究されています。記憶が続く期間と、目の前の反応を区別して考えてみます。

## 猫は何日で飼い主を忘れる？

猫が飼い主を何日で忘れるのか、すべての猫に当てはまる日数はわかっていません。「3日で忘れる」「何年経っても絶対に忘れない」といった単純な説明は、科学的に慎重に扱う必要があります。

猫の記憶や反応には、これまでの経験や関係性、生活環境などが影響します。

関連する内容として「[犬は飼い主の声を聞き分けられる？声を覚える仕組みとは](/column/dog-owner-voice/)」も参考になります。

## 猫は飼い主をどうやって見分ける？

東京大学の齋藤慈子氏・篠塚一貴氏が2013年に発表した研究では、家庭の猫20匹を対象に、名前を呼ぶ飼い主と他人の録音音声への反応を調べました。複数の他人の声を聞かせた後、飼い主の声を聞かせる方法です。

猫は飼い主の声を区別し、耳や頭を動かすなどの反応を示しました。鳴いたり近づいたりする反応が乏しいことと、声を識別していないことは同じではありません。

これは声の識別の研究であり、飼い主と何日離れると忘れるかを測った研究ではありません。また、この実験だけで、においによる認識や猫の記憶全般の持続期間を説明することもできません。

実験方法と反応の評価は、[東京大学の研究発表と原論文への案内](https://www.u-tokyo.ac.jp/focus/ja/press/p01_250327_02.html)をご確認ください。

## 久しぶりに会うとそっけないのはなぜ？

猫は環境の変化に敏感な動物です。長期間離れていた後は、飼い主のにおいや生活のリズムが普段と違っていることもあります。また、猫自身が眠かったり、警戒していたりする場合もあります。

そっけない態度を、すぐに「忘れた証拠」と考える必要はありません。

## 再会したときの接し方

久しぶりに会った猫には、無理に抱きつかず、猫のペースで近づいてもらいましょう。いつもの声で話しかけ、落ち着ける場所を確保することが大切です。急に呼びかけへの反応が悪くなった場合は、聴力や体調の変化が関係している可能性もあります。

気になる変化が続く場合は、獣医師に相談しましょう。

## 再会は猫のペースに合わせる

猫が飼い主を覚えている期間を、日数だけで説明することはできません。声やにおい、毎日の生活の積み重ねが、人を認識する手がかりになっています。久しぶりの再会も、猫自身のペースを大切にしたいですね。
