## 承認後の手順

1. 各原稿・出典の意味と最新版のサービス仕様を管理者が確認し、既存管理画面で確認依頼→確認記録→記事承認を行う。
2. 公開先の関連記事は、公開済みのものだけをrelatedArticleIdsに設定する。新規5本間の接続予定は各原稿末尾と上表に記録してあり、相手の記事が公開されてから設定する。現在の公開記事から未公開slugへリンクしない。
3. 既存の公開準備・非公開exportを利用して公開用JSONへ取り込む。共通getPublishedArticles、一覧・HOME・RelatedServiceColumns・sitemapが公開状態に応じて反映する。記事を出すだけのために各ページへリンクを手書き追加しない。
4. 公開日・更新日・URL・出典・OGPを再検証し、記事公開を含む対象コミットへのマージ・公開承認を別途得る。

既存の家族コラムは日常の見守り方法、紛失対策コラムはなくさない習慣、自治体コラムは地域の連絡体制を中心に扱う。今回の5本は方式の理解・プライバシー・選び方・連絡先の公開・発見後の連絡に分け、既存原稿を書き換えていない。
