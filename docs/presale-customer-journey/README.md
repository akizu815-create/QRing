### 変更前後の文言・構造

- 料金注記：商品代金説明なし → 上表の独立した短い注記。
- 発見者説明：「通常の電話料金は発信した方に別途かかります。」→ 発見者のサービス利用料なしと通常通話料の別負担を段落で区別。
- 5秒未満：「サービス利用料は発生しません。」→「登録者のサービス利用料は発生しません。」＋通常通話料には適用されない旨。
- 個人案内：「つながるQRを使ってみたい方へ」→「商品の入手・利用開始について」。窓口は同じ。一般向け準備中とNEWSをCTAより先に表示。
- モバイル：ロゴ＋マイページ＋メニュー → ロゴ＋メニュー。ログインはメニュー内。PC：濃色のマイページボタン → 控えめなログインリンク。ヘッダー高さ・HERO・使い方・画像は変更しない。

|利用目的|つながるQR一般向け商品の販売開始通知と、その登録確認・配信停止対応のみ。継続営業・別商品案内・アンケート利用は別の同意なしに行わない。購入申込や予約ではないと明示。|
|確認と送信|メール配信サービスのダブルオプトインを候補とし、確認リンクを押した人のみ通知対象。会社ドメインの送信者、SPF/DKIM/DMARC、送信事業者・契約・アクセス権を確認してから採用。サービスが未選定のため実装しない。BCC一斉送信や問い合わせ台帳の流用は避ける。|
|保存|選定・承認した配信サービスの専用リスト。アドレス、目的・同意文面バージョン、同意/確認日時、状態、配信停止日時を最小限保存。保存国・委託条件・権限・削除手順を事前確認。一般公開SheetやGitHubには保存しない。|
|停止・削除|各メールに認証不要の安全な配信停止リンクと会社問い合わせ先。停止後は即時配信対象外。本人確認した削除請求にも対応。通知終了後90日を削除目安として提案し、承認時に保存期間を確定・告知する。停止管理に必要な最小限の記録の扱いも契約・ポリシーに合わせて確定する。|
|重複・不正対策|同一メールの重複は同目的の有効登録1件に整理。確認メールの再送制限・レート制限・必要時ボット対策。登録有無を外部に漏らさない同じ完了メッセージ。確認前のデータを一定期間で削除（7日を候補）。不正な再登録で配信停止状態を解除せず、再度本人確認する。|
|役割|通知＝販売開始の情報を受け取る／問い合わせ＝個別の疑問や利用相談／ペットアンケート＝商品企画への意見。既存アンケートとリストを混ぜない。アンケートの通知同意があっても対象・目的を照合せず新しい一般向け配信へ転用しない。|
