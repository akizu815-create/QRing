## 実装した主な改善

- 16日の要約と冒頭の逐語重複をデータ側で解消。共通レンダラーで黙って削る処理は加えない。

- カテゴリだけで医療・制度・科学・緊急記事に自社CTAを自動追加しない。ペットの捜索・識別記事の既存アンケート、関連性の高いサービス導線は維持。

比較表やチェック項目は、その記事に必要な場合だけ追加した。一律の構成・長さやFAQへ変更していない。学術研究を扱う記事は、営業文を増やさず内容の理解を優先した。

## SEO・AEO・検索実績

SEO titleとH1は全件維持。実績のある財布・紛失対策・保管期間、承認済みの要支援・要介護descriptionを維持した。猫の記事のdescriptionのみ、声の識別研究と分からない記憶期間を区別する文章へ具体化。検索順位上昇やAI引用の増加は実証していない。

接続済みSEOシートを読み取り、GSC最終取得日11/24、シート更新11/27を確認した。直近7日＝11/18〜24、28日＝10/28〜11/24、比較する前期間はJSONに記録。ページ別CTRはクリック数／表示回数、平均順位は表示回数で加重して再計算した。サイトの上位検索語も別集計したが、ページ×検索語やデバイス別は未取得であり、個別記事の検索語へ割り当てていない。

28日分を含め、データのない記事はゼロと断定しない。少数の表示や公開直後のCTR差だけでタイトル変更を決めない。AEOは要約の回答性、適切な見出し・根拠・HTMLの可読性を改善する範囲とし、llms.txtやFAQPageは追加しない。
