## コントラストの方針

生成した画面のcomputed color・背景色を取得し、透過色を背景へ合成したsRGBの相対輝度比を計算する。通常文字は4.5:1以上、大きな文字は3:1以上（24px以上、または18.66px以上かつbold）。小さな英語ラベルや重要な注記も、意味のある文字として扱う。

白背景のink60は約4.54:1だが、アイボリーは約4.40:1、クリームは約4.25:1。ink55は約3.67〜3.87:1。そこで実測で不合格となった本文・注記・日付・図の軸ラベル・費用負担ラベル等を主にink65（約4.96〜5.36:1）へ調整。すべてをink80へは変更しない。

- 共通eyebrowは同じサイズ・行高・字間のままink65へ。ヘッダーの小ラベル、フッターの受付/権利表記、各ページの注記も役割を保つ。
- 大きな「0円」など、元の色で大型文字の基準を満たす表示は維持。
- PRICEの利用料見出し・登録者負担バッジは既存の赤茶系を濃くし、背景と白文字のコントラストを確保。枠・アイコン・画像は追加しない。
- 高齢者ページのグラフ目盛りは文字色だけ濃くする。グラフのデータ・配置・棒・既存画像は変更しない。
- 記事本文は改稿せず、共通表示部品の小文字色だけ変更。承認原稿・記事データ・SEO・日付を変更しない。

写真/グラデーションの上、aria-hiddenの装飾、非表示内容はこの自動色計算から除外。画面全体のWCAG適合認証や、画像内文字の検査を行ったという意味ではない。HEROの写真上のコピーは今回変更しない。測定範囲と結果はcontrast-before.json / contrast-after-390.json / contrast-after-1280.json。
