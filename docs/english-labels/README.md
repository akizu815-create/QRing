## 2. 統一ルール

小さなセクション識別ラベルは共通`.eyebrow`：既存サンセリフ、11px、行高24px、字間0.3em、medium、ink60%。英語は大文字、先頭ダッシュ・末尾ピリオドなし。本文・ブランド名QRing/つながるQR・固有名詞・英文の文章には適用しない。

小ラベルと日本語見出しは原則24px前後。既存の中央寄せ・細線を持つHOMEセクションやページ冒頭は、その構造に合った余白を維持する。ページの大見出し・カードの小ラベル・ナビは別の階層なので同じサイズにしない。色反転が必要な背景は既存のコントラストを維持する。HEROのコピーと画像は変更しない。

## 4. 削除・集約候補と維持

今すぐ削除するリンクはない。料金FAQとアンケートは主CTAと同じ色/強さにしない。ペットアンケートのHOME撤去・ペットページへの集約は選択肢だが、承認なく削除しない。販売通知は未実装なので仮ボタンを追加しない。一般的な「詳しく見る」は対象が分かる文言へ置換し、同じ先への新ボタンは増やさない。

主CTA＝各セクションで判断する次の行動1つを基本に既存の濃色/アウトラインを使用。補助＝グレーのテキスト＋ホバー/フォーカスで分かる下線を基本に、必要箇所だけグリーン。ナビ＝ヘッダー/フッターの既存表示。矢印は既存の必要な箇所に限定し、新しいアイコンやボタン枠は増やさない。全サイトのアンカーに一律スタイルを上書きしない。

## 5. モバイル・検証方針

390px/1280pxで英語ラベルのcomputed style、長い見出しの折返し、横スクロール、リンク文言・href・アンカー到達を比較する。文字色だけでリンクを識別させず、hoverに加えキーボードfocus表示を維持する。リンク変更は原則44/48px相当のタップ領域を維持する。

英語PRはリンク先・画像・SEO/JSON-LD・各法的本文を維持。リンクPRは既存イベント名・送信処理を変えず、アンケートと#161の計測を維持。予約公開・承認原稿・記事データは変更しない。
