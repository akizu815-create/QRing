# HOME・スマートフォンUI改善（レビュー用）

基点main: `f706e18`（PR #153マージ済み）。課題起点の構成を維持し、HOME専用コンポーネントとHEROのモバイルCSSを調整。mainへのマージ・本番公開は行わない。

## 主な変更

- HERO下の「暮らしの『もしも』から見る ↓」と、そのラッパーの余白を削除。代わりの矢印・ボタンは追加しない。
- スマートフォンでは既存写真を3:4のまま全幅表示。人物・犬・首輪とバッグのQRタグを切り取らず、メインコピーは既存の緑の背景部分に置く。写真原本は無変更。
- モバイルHEROの重複する説明文は削除。提供状況はHEROでは表示せず、既存の料金後の個人利用案内で表示する。写真の直後から困りごとへ続け、写真下の余白や代替リンクは追加しない。モバイルの特徴チップと自治体法人ショートカットは非表示にし、下の説明・既存法人セクションで案内する。PC・タブレットのHEROの写真・コピー・配置は維持。
- こんな心配の3シーン・問題提起は維持。導入を指定文「大切な人やペット、持ち物のこと。もしものとき、連絡できる手段はありますか？」に変更。
- モバイルのカード間隔56px→40px、見出し22px、意味のまとまりでのペット見出し改行、リンクの高さ44px以上を設定。既存写真・各活用ページへのリンクは維持。
- 解決策に専用アプリ不要を明記。プライバシー電話番号経由で登録先へ通話する説明と、GPS・紛失自体の防止ではない説明を維持。新しいボタンは追加しない。
- 解決策と使い方のモバイル上下余白を48pxへ揃える。使い方の画像・3ステップは維持。
- 既存の個人問い合わせ案内を、指定の見出し・本文・「利用について問い合わせる」へ更新。窓口は `https://axb.qring.jp/contact` を維持。一般向けの正式リリース準備中という最新案内を維持し、申し込み開始とは表現しない。余白を減らし、大型セクションを追加しない。
- ペットアンケートはmainの現行位置である料金後の1か所を維持。個人問い合わせ・法人相談との目的を分ける。PR #152はマージ済みであり、未マージのアンケート追加PRはない。
