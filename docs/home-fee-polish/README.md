### 保留する具体的な言い換え

「かけ直し」と「5秒未満」はバックエンド・申込画面との照合ができないため、指示書の新しい文への置換を保留する。既存mainの条件文を一覧内へ移し、意味・数値・条件を変えない。

- かけ直し：既存「QRコードのスキャンから1時間以内は、同じ登録者と発見者の組み合わせで再通話・折り返しができます。同一セッション内では追加のサービス利用料はかかりません。1回の通話は最大3分です。」を維持。「同じ1回のご利用」という新しい説明は採用しない。
- 5秒未満：既存「※通話時間が5秒未満の場合、登録者のサービス利用料は発生しません。」「上記の5秒未満の免除は、通常の通話料には適用されません。」を維持。複数回の短時間通話の合算・課金判定・計測起点を推測しない。

リポジトリには申込・課金・電話接続バックエンドの実装を確認できない。外部 `https://axb.qring.jp/` は実行環境のCONNECT 403で閲覧できず、申込画面・実課金は未確認。PRICE/FAQの現行説明と一致することは確認したが、バックエンド確認済みとは扱わない。今回のDL表示は既存公表条件の整理案であり、課金ロジックの変更ではない。

## PRICEのSEO案

変更前：つながるQRの料金案内。通話が成立した1セッションにつき880円（税込）。通常の電話料金は発信した方に別途かかります。通話時間が5秒未満の場合、サービス利用料は発生しません。

変更後：つながるQRの料金案内。登録料・月額基本料は0円。通話が成立したとき、登録者に1回のご利用（1セッション）につき880円（税込）。見つけた方にサービス利用料はかかりません。QRタグ・シール等の商品代金は別途。

指定案をそのまま使用。全条件を詰め込まず、通常通話料・5秒未満・再通話の条件はPRICE本文に維持。title・canonicalは変更しない。既存pageMetadata / PageStructuredDataからOG descriptionとWebPage descriptionへ自動反映される。生成ロジックや他ページの説明を変更しない。検索結果の実表示・採用スニペットは未確認。
