# HOME使い方・登録者／発見者の2段構成案

基点main: `605c15c`（PR #154マージ済み）。文章・レイアウトのみのレビュー用Draft。mainへのマージ・本番公開は行わない。

## レイアウト案

見出し：**登録も、使い方も。かんたん。**

| グループ | PCの横方向の流れ | 説明 |
| --- | --- | --- |
| 登録する方 | 01 QRコードをスキャン ／ 02 必要事項を登録 ／ 03 取り付ける | 最初に設定して、備えておくだけ。 |
| 見つけた方 | 01 QRコードをスキャン ／ 02 「電話をかける」をタップ | 専用アプリ不要。電話番号やIDの入力も不要。 |

スマートフォンでは、登録グループの3項目を上から下へ、その下に発見者グループの2項目を表示。各ステップを数字と短い文字だけで示す。PCは各グループ内を横並びにし、グループ同士は上下に分ける。グループ間の細い仕切り線1本だけを使い、個別カード・枠・矢印・アイコンは追加しない。

登録側には既存SERVICEに合わせ、「『登録者の方』を選択」「電話番号・アカウント情報など」の短い補足を置く。発見者の「入力不要」を登録者に適用しない。

最後のリンク：**詳しい使い方を見る** → `/service/#how`。SERVICEの既存操作説明へ移動する。

## 登録フローとの照合・確認の限界

- `src/components/HowToUse.tsx` と既存画像 `how-to-phone-register.png`・`how-to-account-register.png` を確認。
- SERVICEの入口は「QRコードをスキャンし、『登録者の方』を選択」。詳細は電話番号登録、アカウント情報設定、登録完了。
- 既存の電話番号画面は電話番号入力と「次へ」。アカウント画面にはパスワード・確認用パスワード、都道府県、市区町村、メールアドレスなどの必須表示がある。HOMEの「必要事項」にこれらを集約する。SERVICEの文章・画像は変更しない。
- 「取り付ける」はHOMEの既存説明「QRコードに連絡先を登録し、身近なものに取り付けます」と整合する準備手順。
- 実登録アプリの公開URL `https://axb.qring.jp/` は環境の接続制限（CONNECT 403）で取得できない。実QR識別情報を持たないため、現行の登録を最初から最後まで実行・確認したとは扱わない。
- SMS・メール認証や本人確認等の追加必須操作は未確認。従来の設計資料でも未検証と記録されている。存在しない・不要とは断定せず、HOMEに「認証不要」「入力なしで登録」「数秒／何回タップだけで完了」の表現は追加しない。公開前に実登録フローとの最終照合が必要。

## 画像の扱い

この案はテキストとCSSのみ。画像生成・素材加工・外部画像取得・SVG制作・ダミー画像・絵文字・新規アイコンの追加は行わない。画像ファイルやスクリーンショットはGitHubへ追加しない。

旧HOMEの混在3ステップは置き換えるため、そのセクション内の既存画像・矢印の表示は行わない。既存画像ファイルは削除・編集・差し替えず、そのまま保存し、SERVICEや他ページの画像参照も維持する。HOMEの他の写真・画像も変更しない。

### 将来の承認済み画像を差し込む設計（今回は未実装）

- 差し込み先は `HowItWorks.tsx` の `StepList` 内の各 `li`。各ステップの番号とタイトルの間に、承認された素材がある場合だけ図を表示する想定。
- 予定は登録者3点・発見者2点。共通のスキャン図を再利用するかは素材承認後に判断する。
- 推奨比率：横長 **3:2**。推奨サイズ **900×600px**（PCで約240〜280×160〜187px表示する場合の余裕を持った原本）。サイズは制作前の相談用提案で、一律変更・自動変換はしない。
- 推奨形式：WebP。透過が必要な原本はPNGでも可。SVGは提案・制作しない。
- 将来のCSSは `aspect-ratio: 3 / 2`、`object-fit: contain` を基本に、比率を保持し被写体を切り取らない。スマートフォンでは図の大きさと全体の縦幅を改めて検証する。
- 画像の `src`・`alt`・実寸法は承認済み完成ファイルの受領後にだけ追加する。現段階では空の画像枠・仮画像・余白用のダミー要素を置かない。

## 変更範囲

実装はHOME専用の `src/components/HowItWorks.tsx` のみ。画像読込・SVG矢印・専用スクロールアニメーションを外し、常時HTMLに存在する2つのリストへ変更。新しい計測・依存パッケージ・グローバルCSSは追加しない。

SERVICE、他ページ、SEO設定、構造化データ、料金、仕様、一般向けの提供状況、記事と承認公開管理は変更しない。未マージPR #149/#144/#140/#134には本コンポーネントの変更がなく、競合なし。
