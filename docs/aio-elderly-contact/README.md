対象のQ&Aの回答は番号の仕組みだけで始まっていたため、既存回答にサービス名「つながるQR」と家族への連絡手順を明記した。一般向けの提供状況は既存の `CONSUMER_SERVICE.notice` を参照し、「正式リリースに向けて準備中」を維持する。実際の発見・安全・連絡成立を保証する表現は加えていない。

## 公式情報で確認した機能上の違い

これは機能・操作の整理であり、優劣・料金の比較や導入実績の紹介ではない。「電話番号を公開しない」ことをつながるQRだけの独自機能とは説明しない。

|項目|みまもりあいステッカー|QRコード伝言板の具体例: どこシル伝言板|つながるQR|
|---|---|---|---|
|発見者の入口・操作|ステッカーのフリーダイヤルへ電話し、記載IDを入力|QRコードを読み取り、案内・発見情報の入力画面を利用|QRコードをスキャンし「電話をかける」をタップ|
|家族との連絡|登録先への電話転送・音声通話|公式案内では家族への通知メールと伝言板でのやり取り|プライバシー電話番号を経由した音声通話|
|個人の電話番号|公式案内に、双方の個人情報を公開せず連絡できるとの説明|個人情報を開示しない情報共有。発見情報に電話番号・メールアドレスを入力しないよう案内|発見者と登録者の本来の電話番号を相手に表示しない|
|この監査での説明範囲|ステッカーの電話転送。捜索アプリとの機能を混同しない|QRコード伝言板一般の全機能として断定せず、一例として扱う。音声機能が一切ないと断定しない|GPS追跡・転倒自動検知はない。発見者の操作と登録先の応答が必要。一般向けは準備中の案内を維持|

確認資料（読み取りのみ。申し込み・フォーム送信なし）:

- [みまもりあいプロジェクト公式](https://mimamoriai.net/): 緊急連絡ステッカーの説明に「フリーダイヤルへ電話→ID入力→事前登録した家族の電話へ連絡」の記載を確認。
- [どこシル伝言板の提供元公式案内](https://mirai-town.com/product/dokoshiru-briefing/): QR読み取り、家族への通知、発見情報入力後の伝言板での連絡、電話番号等を入力しない注意を確認。読み取り通知と発見情報入力後の通知の説明は分けており、つながるQRの自動通知として転用していない。
- [つながるQR SERVICE](https://www.qring.jp/service/)に対応する現行mainのコード、`src/config/consumerService.ts`、高齢者向けFAQ・比較表を照合。自社の提供状況や料金は変更なし。

この表と出典URLは監査用の記録であり、公表ページには追加しない。サービス紹介ページへの追加説明と競合外部リンクは今回削除した。既存の一般的な見守り比較表だけを維持し、第三者の受賞・導入数・協定・顧客実績は掲載していない。
