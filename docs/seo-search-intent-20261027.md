# 見守り・紛失対策の検索意図に合わせた改善

作成日：2026年10月27日。基準：main `980defd8cb0f0c33924cb76fa008163fcbd880a7`。

## 実装した内容

会社名・サービス名を知らずに「高齢者の見守り」「落とし物対策」を探す方が、目的に合う説明へ進めるようにした。

- HOME：既存HEROの写真とコピーを維持し、その直後に用途を説明する見えるH1・サービス定義・用途別リンクを配置。隠れていた旧H1は置換した。
- 高齢者ページ：外出時の発見後連絡を説明する見出し・冒頭文と3ステップを追加。室内見守りとの役割の違いを説明し、統計セクションをサービス説明より後ろへ移動。統計の値・出典は未変更。
- 持ち物ページ：鍵・財布の紛失に備える説明、電話番号をタグに直接書かず連絡する仕組み、比較記事へのリンクを追加。
- 高齢者・持ち物ページ：用途別4問と共通2問ずつ、合計10種類のFAQを追加。HTMLのdetails/summaryを使用し、回答を初期HTMLに含めた。料金は既存のベーシック案内に合わせ、提供状況は共通設定を参照。
- SERVICE：日本語の主見出しと定義文、意味の分かる用途別リンクへ更新。共通PageHeaderは日本語主見出しを任意で指定できるようにし、他ページの既存表示は維持。
- 新規記事：`/column/elderly-monitoring/`、`/column/lost-item-preparation/`。室内の安否確認、位置確認、発見後の連絡の役割を区別し、各公式情報へのリンクと確認日を記載。
- 記事一覧：`/column/`。HOME、フッター、用途別ページから記事へ進めるようにした。
- メタ情報：HOME・高齢者・持ち物・SERVICEのtitle/descriptionを更新。新規3ページも既存のSEO_PAGESに追加し、canonical、OGP、WebPage、sitemapを同じ定義から生成する。

AirTagにも紛失時の連絡方法を表示できる場合があることを記載し、「位置確認機器には連絡機能がない」といった説明はしない。findの施設向けサービスと個人向けfind returnを区別する。つながるQRを位置追跡・転倒検知・返還保証のサービスとして表現しない。

既存の料金本文、規約、問い合わせ先、マイページ、robotsのアクセス方針、公開ワークフローは変更していない。robotsは既存の全体クロール許可を維持。AI専用ファイル・FAQリッチリザルト・検索順位の保証は追加していない。

2. 高齢者・持ち物ページの一般語による表示・クリックと、料金・問い合わせへの遷移。

月間検索数・Googleの語別上位順位・問い合わせ増加は未測定。本変更は検索意図に合う情報と導線を整備するもので、順位・問い合わせ件数の改善を実測したものではない。
