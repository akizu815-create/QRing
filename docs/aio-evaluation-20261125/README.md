## 既存構造との関係

mainにはHOMEのOrganization/WebSite、各ページのWebPage/BreadcrumbList、SERVICEのService、コラムのArticle等がある。FAQ本文はサーバー生成HTMLにあり、FAQPageはmainにない。今回案に同一FAQPageの二重出力はないが、同じページの機械可読な表現・検証対象が増える。

FAQPageはFAQ_CATEGORIESから生成し、手書きのQ&Aを二重管理する方式ではない。ただし `item.answer` のみを出力するため、表示上別途付く関連リンクは同じ形で出ない。「表示内容の全要素が常に一致する」という説明は広すぎる。主Q&A文が同じデータから生成される点は確認できる。

llms.txtはSERVICE/PRICE/FAQ等の情報を再要約し、サイトマップと一部同じURLを列挙する。robots.txtやcanonicalの代替にはならない。既存HTMLと内部リンクからアクセスできる情報が中心。
