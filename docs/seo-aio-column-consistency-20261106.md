## Search Consoleの基準値と取得手順

この実行環境にはGoogle認証変数・認証ファイル・元プロジェクトの.env・既存SEOデータベースがないため、GSCへの接続・実データ取得はできていない。表示回数・クリック数・CTR・平均順位は未取得で、数値を0や推定で埋めない。docs/gsc-baseline-template-20261106.csvは未取得を明示する空欄テンプレートであり、実測の基準値ではない。

管理者の既存Search Consoleで、検索タイプWeb・同じ期間と条件に揃え、直近確定28日と前28日を比較して取得する。

1. 「電話 QR」「高齢者 見守り QR」「認知症 迷子 QR」「QR 電話番号 非公開」を完全一致で確認する。
2. 関連する「QRコード」「認知症」「外出」「電話番号非公開」等のロングテールも、正規表現／部分一致の条件を明記して別集計する。
3. クリック・表示回数・CTR・平均掲載順位をCSVにエクスポートする。国・デバイス・検索タイプ・期間・ページ条件を記録し、比較時に一致させる。
4. 実CSVは公開srcやGitへ置かず、既存の非公開SEO保存先で管理する。設定済みの安全な認証がある端末では既存CLIを再利用できる。
