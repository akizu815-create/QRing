# 災害時、家族と連絡が取れなかったら？安否確認の方法と事前の備え

**SEOタイトル：** 災害時に家族と連絡が取れないときは？171と安否確認の方法

**メタディスクリプション：** 地震などの災害時に家族と電話がつながらない場合、どうすればよいのでしょうか？災害用伝言ダイヤル171や安否確認の方法、事前に決めたい家族のルールを紹介します。

大きな地震が起きたとき、真っ先に気になるのは家族の安否ではないでしょうか。

しかし、災害時には電話がつながりにくくなる場合があります。

そんなとき、どのように連絡を取ればよいのでしょうか。

### なぜ災害時は電話がつながらないの？

大きな災害が発生すると、多くの人が一斉に電話をかけます。

通信が集中することで、通常より電話がつながりにくくなる場合があります。

また、通信設備の被害や停電などが影響することもあります。

そのため、普段使っている電話だけに頼らない準備が大切です。

### 災害用伝言ダイヤル「171」とは？

災害用伝言ダイヤル「171」は、災害時に安否情報を音声で登録・確認するためのサービスです。

電話番号を手がかりに伝言を残したり、聞いたりできます。

ただし、利用できる条件やサービスの提供状況は、災害の規模などによって異なります。

NTTなどの公式案内で、事前に使い方を確認しておきましょう。

### 災害用伝言板も知っておこう

通信事業者などが提供する災害用伝言板も、安否確認の手段の一つです。

メッセージアプリやSNSを利用する方法もありますが、通信環境によっては使えない場合があります。

一つの方法だけでなく、複数の連絡手段を知っておくことが重要です。

### 家族で決めておきたい三つのこと

災害が起きる前に、家族で次のことを話し合っておきましょう。

**① 避難場所**

自宅や学校、職場の近くにある避難場所を確認します。

**② 連絡方法**

電話がつながらない場合に、どのサービスを使うか決めておきます。

**③ 連絡が取れない場合の行動**

まずは自分の安全を確保し、どこへ避難するかを共有します。

### 紙のメモも役に立つ

スマートフォンの電池が切れたり、故障したりすることもあります。

家族の連絡先や避難先などを、紙に控えておくことも一つの備えです。

個人情報の管理に注意しながら、必要な情報をまとめておきましょう。

### まとめ

災害時は、いつもの連絡手段が使えるとは限りません。

家族と連絡が取れない場合に備え、複数の安否確認方法と避難先を事前に決めておくことが大切です。
