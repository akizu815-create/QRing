## 根拠と限界（2026-11-24に閲覧）

- [株式会社三通の特許紹介](https://sanntsu.com/corporate/patent/)：第7460140号、「QRコードを用いた暗号化呼接続方法」の紹介を確認。これはQRingの取得・許諾範囲を示す資料ではない。
- [JST J-GLOBALの特許情報](https://jglobal.jst.go.jp/detail?JGLOBAL_ID=202403005973822610)：特許番号、出願人/特許権者欄の株式会社三通、請求項の抜粋を確認。
- [Google Patents JP7460140B2](https://patents.google.com/patent/JP7460140B2/ja)：公開された技術説明・請求項、原出願人表示を参照。法的状態の表示は同サイトも法的結論ではないと注記している。J-PlatPatの登録原簿で現時点の権利状態を確認したものではない。

公表資料にある番号・出願人/特許権者の表示は確認できたが、QRingへの実施許諾契約・再許諾・表示許諾、実際のつながるQRの実装と各請求項の対応は未確認。公開特許の説明だけから、登録者/発見者双方の番号非公開、アプリ不要・入力不要の全機能が特許によって保証・独占されるとは結論しない。QRingを特許権者として表示せず、三通の名前を協業・導入実績としてサイトUIへ追加しない。

## 承認・弁理士確認が必要な事項

1. 「特許技術を活用した通話サービス『つながるQR』」「特許技術を活用した独自の通話接続方式」の掲載可能範囲と、対象実装への特許技術適用の裏付け。
2. 実施許諾の当事者・対象・期間・表示条件、特許番号や出典の掲載条件。契約の存在・不存在を本監査では断定しない。
3. 発見者の番号入力不要を含む現在の通話フローと特許請求項の対応。特許全体を機能一覧の保証のように表示しない。
4. 最新の権利状態・権利者。公表データの出願人情報だけで現在の登録原簿を代替しない。

「当社取得」「世界初」「唯一」「他社実現不可」「特許だから安全」「通話成功・完全な個人情報保護を保証」は採用しない。法的文書は変更しない。上記未確認事項について承認前に本番公開しない。
