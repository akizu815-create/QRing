## テーマ候補の扱い

`scripts/editorial/topics.py` を既存生成計画に接続。電話QRの作り方・仕組み・注意点・非公開型との差は1つの候補群に統合。
高齢者の準備・自治体の運用・GPS／伝言板／音声連絡の比較は、既存ページの拡充を先に検討する。
公開記事だけでなく私有下書きも類似照合に含め、取得済みのGSC観測との対応がない場合は `not_acquired` を返す。
候補そのものの `generationAuthorized` は常にfalse。既存の生成実行・承認・費用制限を迂回せず、生成器を有効化する変更ではない。
今回、新規記事の生成・公開、既存記事の自動編集は実施していない。
