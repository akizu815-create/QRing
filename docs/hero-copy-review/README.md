## プレビューの仕組み・安全境界

`npm run build`後、`postbuild`が次の条件を満たす場合だけ`out/review/hero-copy/`へ比較HTMLを生成する。

- Cloudflare Pagesの非mainブランチプレビュー、またはローカルで明示的に `QRING_HERO_REVIEW=1 npm run review:hero` を実行した場合。
- `CF_PAGES_BRANCH=main` のときは、ローカル用フラグがあっても生成しない。通常ローカルビルドでも生成しない。既存の生成先が残っていればその比較資料ディレクトリだけ削除する。

元の出力HTMLをコピーして追加文だけ挿入する。元HOME出力・CSS・画像は上書きしない。画像の加工・生成・外部取得はない。比較資料ではアプリのhydration/GA4/JSON-LD等のscriptを除き、noindex,nofollowを付ける。sitemapには追加しない。比較ボードの幅切替のみローカルなJavaScriptを使用し、通信・計測しない。

静的比較資料なのでヘッダーメニュー・アプリのフォーム等の操作検証用ではない。実ページの構成を確定したり、新しい利用開始CTAを追加したものではない。公開処理・記事承認・予約公開ロジックは変更しない。

通常ビルドで比較資料非出力、明示ローカル出力、実outに対するmainガードとルートHTMLのSHA256一致も確認。ルートページとサイト本体を変更せず、比較資料に限って候補を表示している。
