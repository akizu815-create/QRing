設定 `src/config/homeColumnPicks.json` はmainと同じ `elderly-monitoring / lost-dog-preparation / lost-item-preparation`。3件・日付非表示・既存の公開済み判定・不足時フォールバック・静的出力/ライブ検査をすべて維持する。未公開記事を採用しない。選定の自動更新や新しい計測設定は追加しない。
