## 回答・通知の運用

アンケートの回答と販売開始案内への同意は別の目的として扱う。販売案内の送信対象は、明示的な「希望する」の同意が記録され、有効なメールアドレスがある人のみとする。「希望しない」、無回答、同意不明の人は除外し、メール欄に入力があっても同意の代わりにしない。アンケート回答だけを理由に営業メールを送信しない。

本PRはメール配信、回答データの取得・保管、同意管理を実装しない。フォーム管理者・配信担当者が最終設定と配信対象抽出を確認する。サイト側ではメールや回答内容を収集しない。

## 計測

既存のlayoutのgtagのみ利用し、新しいGAタグ・計測ID・dataLayerの初期化・グローバルなクリック監視は追加しない。

- イベント：`pet_survey_click`
- `source_page`：クリック時のpathname（クエリやメールアドレスは送らない）
- `placement`：`home` / `pets` / `column`

各リンクのonClickから1回送る。gtagが利用できない環境でもリンクを開ける。GA4拡張計測の汎用的な外部クリック`click`とは別イベントなので、両者を加算してアンケートクリック数にしない。回答完了・通知同意をこのイベントから推定しない。回答完了数はフォーム側で確認する必要があり、本PRでは未計測。GA4の管理画面・イベント設定は変更していない。
