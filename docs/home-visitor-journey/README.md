## 確認いただきたい文章

### 困りごと

見出し：「こんな心配、ありませんか？」

導入：「大切な人やペット、持ち物のこと。『見つかったあと、連絡がついたら』と思う場面があります。」

- 家族：「外出先で家族が道に迷ったとき。」「声をかけてくれた方から、家族に連絡してもらうには。」
- ペット：「迷子のペットを保護してもらえたとき。」「飼い主に連絡してほしい。でも、迷子札に電話番号は書きたくない。」
- 持ち物：「大切な鍵や財布を落としたとき。」「拾ってくれた方が、持ち主に連絡できる手段があったら。」

既存の3枚の写真・alt・各活用ページへのリンクを維持し、事故発生や紛失を防げるとは表現しない。

### 解決策

見出し：「その『もしも』に、つながるQR。」

「お互いの電話番号を公開せずに、声で連絡できる仕組みです。」

「持ち物や首輪などのQRコードから、見つけてくださった方が、ご家族や飼い主・持ち主などの登録先へ電話をかけられます。通話にはプライバシー電話番号を使用します。」

「GPSによる位置追跡や、紛失そのものを防ぐサービスではありません。見つけてくださった方からの連絡を支えます。」

位置追跡機能がない説明は既存のuseCaseFaqsと整合。新規の技術仕様・料金・提供状況は設定しない。

## CTAの役割

- HERO：既存のSERVICE・自治体法人ショートカットを維持。写真ステージの外に「暮らしの『もしも』から見る ↓」を追加し、固定ヘッダーに重ならない位置へ移動。
- 困りごとの3場面：既存の各活用ページへ。ここではアンケートを表示しない。
- 解決策：追加CTAを設けず、次の3ステップへ読む流れを維持。
- 使い方：旧活用シーン末尾の汎用SERVICEリンクを移し、仕組みの詳細リンクを1つ設置。
- 料金：料金・FAQの既存リンクを維持。
- 個人：既存の問い合わせ先 `https://axb.qring.jp/contact` に「個人での利用について問い合わせる」。専用の別フォームや販売申込みを作ったとは扱わない。
- ペットアンケート：HOME内は料金後の1か所に移動。小さなテキストリンクを維持。イベントは既存の `pet_survey_click`、`source_page=/`、`placement=home` のまま。
- 自治体・法人：既存のForBusinessセクションと相談導線を維持。個人問い合わせと同じ既存窓口だが、文言と配置で目的を区別する。

一般向けサービスの正式リリース準備中という案内を維持。ペットフォームの公開設定・送信可否・最終設問は引き続き未確認で、本プレビューはそれらの確認を意味しない。

## 変更範囲と競合

HOME専用のpage、UseCases、HowItWorks、PriceSection、および新しいHomeSolutionのみ。各コンポーネントはHOME以外では使われていないことを検索で確認した。HERO画像・CSS module・グローバルCSS・ヘッダー・他ページ・SEO設定・構造化データ・コラム・法的文書・公開管理・計測基盤を変更しない。

未マージPR #149（SEO監査）、#144（画像監査）、#140（分析・SERVICE側の改善準備）、#134（下書き資料）の変更ファイル一覧を照合し、今回の実装ファイルとの重複なし。PR #152のアンケート導線はmainに取り込まれた状態から移動する。

## 検証

ビルド、test:columns、test:scheduled-columns、check:column-export、check:column-navigationを実施。変更前後の静的HTMLを比較し、HEROステージ、写真・画像・alt・寸法、全ページのSEO/構造化データ、HOME以外のmain DOMの一致を確認する。
