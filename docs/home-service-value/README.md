# HOME・SERVICE：利用価値と特許技術の訴求改善案

基点main `dd735a0`。PR #155/#156/#157のマージと各マージコミットが取り込まれていることを確認。承認前のマージ・本番公開は行わない。

## 変更範囲・訴求

実装は `src/components/HomeSolution.tsx` と `src/app/service/page.tsx` の2ファイル。HOMEの順序、HERO、3シーン、登録3・発見2の図解と5画像、料金、法人案内を維持する。

HOMEは、困りごとの直後に「電話番号を教えずに、直接話せる。」という体験を提示し、操作→その操作を支える特許技術→SERVICEの仕組みへ読む順序にする。操作入力をまとめたステップ図は既存HOW IT WORKSだけで説明する。

直接通話・双方の番号非公開は本文で伝えるため、特徴表示は「専用アプリ不要」「発見者の番号入力不要」の2項目に絞る。控えめな文字と縦の区切り線のみで、カード・バッジ・アイコンを追加しない。GPS・紛失防止ではない注意書きは13px・行高28pxの補足として、技術説明と詳細リンクの後に維持する。

SERVICEは、連絡先の電話番号を表示する方法と、プライバシー電話番号を使った通話接続の違いを説明し、既存図の前で双方の番号を知らずに通話できることを明示する。競合名・比較表・他社機能の断定は追加しない。

### SERVICE プライバシー通話

変更前：

> 発見者と登録者の間に、プライバシー電話番号を使用します。お互いの電話番号を相手に表示せず、直接会話できます。

変更後：

> 発見した方は登録者の電話番号を、登録者は発見した方の電話番号を知る必要がありません。
>
> プライバシー電話番号が通話をつなぎ、双方の電話番号を相手へ公開せずに、直接会話できます。
>
> 専用アプリや、発見者による電話番号・IDの入力は不要です。

既存接続図、最大3分・1時間、折り返し、着信番号帯、料金・FAQ等の内部リンク、CTAは無変更。
