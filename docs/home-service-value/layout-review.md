# PR #158 レイアウト見直し

ユーザーの確認後、「番号非公開の直接通話」「簡単さ」「特許技術」の3つを視覚的に区別する。文章内容は基本的に維持し、新しい大型図解・カード・枠・アイコン・画像は追加しない。スクリーンショットは最新の指示により作成しない。

最新main `965a78e`（11月24日コラム公開済み）を取り込んだうえで作業。公開記事24件はmainと同じ状態を保つ。

## HOME SOLUTION

| 要素 | 初稿 | 見直し後 |
| --- | --- | --- |
| その「もしも」に、つながるQR。 | 大きなセクション見出し | 見出し文とH2を維持し、補助的な文字サイズ・グレーへ |
| 電話番号を教えずに、直接話せる。 | 本文より少し大きな一続きのコピー | セクション内で最も大きく、二行に分ける。重要な「直接話せる。」だけグリーン |
| QRコードをスキャンして、「電話をかける」をタップするだけ。 | 他の説明と同じ文字組み | 独立した18px（PC20px）の強調行。電話操作の語句のみグリーン |
| お互いの電話番号を公開せず、その場で声をつなぎます。 | 操作説明と同じ段落 | 操作行の下の短い補足として分離。文言は維持 |
| 特徴 | 専用アプリ不要、発見者の番号入力不要 | 指定の「番号非公開」を加えて3項目。控えめな文字だけで整理 |
| 特許技術を活用した、独自の通話接続方式。 | 本文に近い一続きの文章 | 細い線の下に独立したH3。前半をラベル、後半を24px（PC28px）の見出しとして表示 |
| 技術の補足・リンク | 見出しの下の文章 | PCでは技術見出しの横、スマートフォンでは下に配置 |
| GPS等の注意書き | 補足 | 内容・可読性を維持し、主訴求より控えめな補足のまま |

390pxの計測では、節見出し22px、主コピー30px、操作18px、通常本文14px、接続方式24px。本文を小さく詰めず、文字サイズ・色・段落間隔の差で優先順位をつける。PC1280pxでは主コピー54px・通常本文16px。実際の折り返しは端末のフォントによる。

SOLUTIONの全高は390pxで約779→859px。主コピーの強調と読みやすい分割に伴う増加で、縮小して押し込むことはしない。HERO・USE CASES・HOW IT WORKS・PRICEの内容や配置指定は変更しない。

## SERVICE INTRO

- 大見出し「小さなQRコードに、大きな安心を。」は維持。
- 初稿の「つながるQRは、電話番号を教えずに、見つけてくださった方と直接話せるサービスです。」を、同じ価値を示す独立見出し「電話番号を教えずに、直接話せる。」に整理。見出しを追加した直後に同じ本文を重ねない。
- 電話番号表示との違いを説明する段落と、登録先へ発信できることを説明する段落を分割。2文の内容は初稿のまま。
- 「特許技術を活用した、独自の通話接続方式。」は、既存INTROの文章枠内の細い線の下に独立したH3として配置。
- 特許番号「活用技術：特許第7460140号」は、技術見出しに付随する注記へ移動。番号・意味は変えず、取得者・独占性・安全保証の主張も追加しない。
- 本文は16px（PC18px）を維持。価値・接続方式の見出しは24px（PC28px）、番号は12px。写真、活用リンク、プライバシー通話の説明、接続図、操作手順、時間・料金・セッション・CTAは変更しない。
