## レイアウトと品質

- PR #155の2グループ・3＋2ステップを維持。見出し、各ステップ名、グループ説明、詳細リンク `/service/#how` を維持。
- 登録03の指定補足を追加。発見02には「登録先へ電話をかけられます。」を添え、操作後の連絡先が分かるようにする。
- 「イラストは操作のイメージです。」と明記。添付の新規登録イラストを、実画面の正確な再現とは説明しない。
- モバイルは登録→発見の順で縦並び。PC・タブレットは各グループのステップを横並び。グループ間の控えめな線は維持し、カードや矢印は追加しない。
- 5画像すべてに共通の最大幅250px・高さ160px（768px以上は176px）の表示枠を使用。画像は `object-fit: contain` で、元の比率を保ち、被写体を切り取らない。
- ステップ番号→画像の間8px、画像→見出しの間8px、モバイルのステップ間24px。補足13px・行高24pxとし、小さくしすぎない。
- 添付JPEGは白背景、既存PNGは透過を含むため、画像に処理を加えずに四角い背景を目立たせないよう、HOME使い方セクションを白地へ変更。CSSのフィルター・ブレンド・マスク・画像の色変更は使わない。
- 新画像は淡い灰色の線、既存はやや暖かい灰色と控えめなグリーン。原本どおりの色差を維持。共通枠で目視し、背景枠・黒や灰色の縁・被写体の欠けを認めなかった。
- 既存PNGの表示幅は元画像のピクセル寸法未満で、無理な拡大をしない。JPEGも原寸以下。各素材の内部余白・線の濃さは原本のままで、完全な同一化のための素材加工はしていない。

390pxのセクション全高は約1949px（5画像・説明・グループ見出し・余白・詳細リンクを含む）。160pxの画像枠を使い、旧HOMEの画像210px＋段間の大きな矢印余白の構成には戻していない。画像なしPR #155との縦幅増加は、承認済み5枚の配置に伴うもの。
